# 교수학습 및 평가 운영 계획 작성기

「과목별 교수학습 및 평가 운영 계획」 양식(2026학년도 2학기)을 웹 화면에 그대로 옮겨 놓은 작성 도구입니다.
화면에서 양식 칸을 바로 클릭해 채우고, **한글·워드(.docx)** 로 내려받거나 **인쇄/PDF** 로 저장할 수 있습니다.

## 주요 기능

| 양식 항목 | 사이트에서 할 수 있는 일 |
| --- | --- |
| 표지(학교명·학년·학기·지도교사 등) | 칸을 눌러 입력, 분할점수산출유형 고정/추정 선택 |
| Ⅰ. 교수학습-평가 계획 | 주차별 행 자동 생성(1·2학기), 행 추가/삭제/이동, **시수 입력 시 누계 자동 계산**, 성취기준 목록에서 골라 넣기 |
| Ⅱ. 성취기준별 성취수준 | 과목을 고르면 **성취기준·A~E 성취수준이 자동으로 채워짐** (수정·삭제·직접 추가 가능) |
| Ⅲ-6. 평가 개요표 | 정기시험·수행평가 영역 추가/삭제, **반영비율 합계 100% 자동 확인** |
| 동점자 처리 기준 순위 | 평가 개요표의 영역 이름·비율이 자동 반영 |
| Ⅲ-8. 수행평가 영역별 세부기준 | 수행평가 영역마다 채점기준표 자동 생성, **평가 요소 배점 합 = 영역만점 자동 확인**, Ⅱ의 성취수준을 평가기준으로 가져오기 |
| Ⅲ-12. 학기 단위 성취수준 | Ⅱ의 성취기준별 성취수준으로 초안 자동 작성 |
| 그 밖의 항목 | 양식의 기본 문구가 미리 들어 있으며 자유롭게 수정 |

- 작성 내용은 브라우저에 **자동 저장**됩니다 (같은 컴퓨터·같은 브라우저).
- **[파일로 저장]** → `.json` 파일로 보관하거나 교과협의회 동료에게 전달, **[파일 열기]** 로 이어서 작성.
- **[예시 불러오기]** 로 양식의 〈예시〉(공통국어1)를 그대로 불러와 참고할 수 있습니다.

## 사용 방법

별도 설치가 필요 없습니다. `index.html` 을 브라우저(크롬·엣지·웨일)로 열면 됩니다.

웹 주소로 함께 쓰려면 GitHub Pages 를 켜세요:
저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`**
→ 잠시 후 `https://<계정>.github.io/<저장소>/` 주소로 접속할 수 있습니다.

## 성취기준(성취수준) 데이터

`data/standards/` 에 **2022 개정 고등학교 성취수준 자료(한국교육과정평가원) 31개 PDF에서 변환한 172개 과목**이 들어 있습니다.
(공통·선택·계열 선택 과목, 성취기준 약 2,400개) 공통국어1은 양식 한글 파일의 내용과 글자 하나까지 일치함을 확인했습니다.
PDF에서 일부 칸이 읽히지 않은 성취기준 4개(보건 2, 고급 지구과학 2)는 사이트에서 불러와 빠진 수준을 직접 채워 주세요.

## 성취기준(성취수준) 데이터 추가하기 — PDF가 많을 때

과목별 성취수준 PDF는 채팅에 올릴 필요 없이 **이 저장소의 `pdfs/` 폴더에 올리면 자동으로 변환**됩니다.

1. GitHub 저장소 화면에서 `pdfs` 폴더로 이동 → **Add file → Upload files**
2. PDF 파일을 끌어다 놓기 (한 번에 최대 100개, 파일당 25MB 이하 — 큰 파일은 아래 참고)
3. **Commit changes** 를 누르면 GitHub Actions(「성취수준 PDF 변환」)가 PDF를 읽어
   과목마다 `data/standards/과목명.js` 를 만들고 자동으로 커밋합니다. (Actions 탭에서 변환 결과 확인)
4. 사이트의 Ⅱ에서 과목을 선택해 불러온 뒤 내용이 맞는지 확인하세요.

**파일 이름이 제각각이어도, 한 PDF에 여러 과목이 있어도 괜찮습니다.**

- 과목은 성취기준 코드 앞부분으로 나눕니다: `[10공국1-01-01]` → `10공국1`, `[12대수01-01]` → `12대수`
- 과목명은 PDF 본문에서 찾습니다 (예: 코드 `12대수` → 본문의 '대수'). 교과군(국어·수학…)도 과목명으로 추정합니다.
- 과목명을 잘못 찾았거나 못 찾은 경우(목록에 `12대수` 처럼 코드로 표시됨)에는
  `tools/subject_names.json` 에 `"12대수": "대수"` 처럼 적어 커밋하면 전체가 다시 변환됩니다.

### 25MB가 넘는 PDF

GitHub 웹 화면은 파일당 25MB까지만 올릴 수 있습니다. 다음 중 편한 방법을 쓰세요.

- **PDF 나누기**: 크롬으로 PDF 열기 → 인쇄(Ctrl+P) → 대상 'PDF로 저장' → 페이지 범위 지정(예: 1-80, 81-160) → 저장.
  나눈 파일을 그대로 올리면 됩니다. 한 과목이 두 파일에 걸쳐도 코드 기준으로 합쳐집니다.
  (또는 iLovePDF·알PDF 등의 '분할' 기능)
- **GitHub Desktop** 프로그램으로 올리기: 파일당 100MB까지 가능합니다.

직접 변환하려면:

```bash
pip install pdfplumber
python tools/pdf_to_standards.py pdfs/*.pdf                 # 여러 파일 한꺼번에
python tools/pdf_to_standards.py 파일.pdf --pages 10-40 --dry-run   # 저장 없이 결과만 확인
```

> PDF마다 표 모양이 달라 일부 문장이 잘리거나 합쳐질 수 있습니다. 변환 결과 요약에 ⚠ 표시된 항목은
> 사이트에서 불러와 직접 고치면 됩니다. 스캔(이미지) PDF는 글자를 읽을 수 없어 변환되지 않습니다.

성취기준 데이터 형식(`data/standards/*.js`):

```js
registerStandards({
  "id": "공통국어1", "subject": "공통국어1", "group": "국어",
  "areas": [
    { "name": "듣기·말하기",
      "standards": [
        { "code": "10공국1-01-01", "text": "대화의 원리를 고려하여 …",
          "levels": { "A": "…", "B": "…", "C": "…", "D": "…", "E": "…" } } ] } ]
});
```

같은 형식의 `.json` 파일은 사이트의 [JSON 파일에서 불러오기] 로도 바로 쓸 수 있습니다.

## 파일 구성

```
index.html                 화면
css/style.css              양식 모양(A4) 및 인쇄 설정
js/defaults.js             양식 기본 문구, 주차, 성취율 표
js/example.js              양식 〈예시〉(공통국어1) 데이터
js/app.js                  입력·자동계산·저장
js/docx.js                 .docx 내보내기 (외부 라이브러리 없음)
data/standards/            과목별 성취기준·성취수준 데이터
tools/pdf_to_standards.py  성취수준 PDF → 데이터 변환 도구
tools/subject_names.json   과목명 직접 지정(코드 앞부분 → 과목명)
pdfs/                      변환할 PDF를 올리는 폴더
.github/workflows/         PDF 자동 변환 설정
```
