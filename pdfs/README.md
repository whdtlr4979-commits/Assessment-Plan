# 성취수준 PDF 올리는 폴더

이 폴더에 성취수준 PDF를 올리면 GitHub Actions 가 자동으로 과목별
`data/standards/과목명.js` 로 변환해 사이트의 과목 선택 목록에 추가합니다.

- **파일 이름은 아무렇게나 되어 있어도 됩니다.** 한 PDF에 여러 과목이 들어 있어도 됩니다.
  (성취기준 코드 `[10공국1-01-01]`, `[12대수01-01]` 의 앞부분으로 과목을 나누고, 본문에서 과목명을 찾습니다)
- GitHub 웹 화면: 이 폴더에서 **Add file → Upload files** → PDF 끌어다 놓기 → **Commit changes**
  (한 번에 최대 100개, **파일당 25MB 이하** — 큰 파일은 크롬 인쇄 'PDF로 저장'에서 페이지 범위를 나눠 저장해 올리세요)
- 변환 결과는 저장소의 **Actions** 탭 「성취수준 PDF 변환」에서 확인할 수 있습니다.
- 과목명이 틀리게 나오면 `tools/subject_names.json` 에 `"코드앞부분": "과목명"` 을 적어 커밋하세요.
